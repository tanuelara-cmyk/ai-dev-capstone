# AI Task Manager

A simple web-based task manager created as a capstone project for the FlyRank AI-assisted development track.

## Features

- Add tasks

- View tasks

- Mark tasks as completed

- Delete tasks

## Tech Stack

- HTML

- CSS

- JavaScript

- Git

- Cursor
## How to Run

1. Open `index.html` in a web browser.
2. Enter a task in the input field.
3. Click the Add Task button.
4. Use Complete to mark a task as completed.
5. Use Delete to remove a task.

## Current Features

- Task creation
- Task completion
- Task deletion
- Simple and clean interface
## Goal

The goal of this project is to learn AI-assisted development, Git workflows, and practical web development.
